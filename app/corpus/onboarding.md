# Getting Started with Acme Cloud

## Creating an account
Sign up at console.acmecloud.example with an email address. Email verification is required before creating a project.

## First project
Every new account receives a $100 free credit that expires 60 days after sign-up.
Create a project, choose a region, and deploy using the `acme deploy` command from the Acme CLI.

## Installing the CLI
The Acme CLI is installed with `pip install acme-cli` and requires Python 3.9 or newer.
Authenticate the CLI with `acme login`, which opens a browser window.

## Getting help
New users can book a free 30-minute onboarding call during their first 14 days.
