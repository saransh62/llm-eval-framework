# Object Storage

## Overview
Acme Object Storage is an S3-compatible service available on all plans.

## Pricing
Storage costs $0.02 per GB per month. Egress costs $0.05 per GB after the first 100 GB each month, which is free.

## Limits
The maximum object size is 5 TB. Buckets can hold an unlimited number of objects.
Bucket names must be globally unique and between 3 and 63 characters long.

## Versioning
Object versioning is off by default and can be enabled per bucket. Deleted versions are kept for 30 days.
